# Repositório destinado às atividades da disciplina de Programacao-Web-II-2026-2027

## Objetivo

Este repositório tem o objetivo de armazenar e organizar as atividades desenvolvidas durante a disciplina, permitindo acompanhar a resolução das questões teóricas e práticas e a evolução dos conhecimentos sobre JavaScript,HTML,CSS e mais.

## Organização

As atividades estão organizadas em pastas de acordo com cada lista de exercícios.

```
atividades/
└── lista-01/
    ├── respostas.md
    ├── questao-2-a.js
    ├── questao-2-b.js
    └── ...
```

* `atividades/`: contém as listas de atividades da disciplina.
* `lista-01/`: contém os arquivos referentes à primeira lista.
* `respostas.md`: contém as respostas das questões teóricas.
* `questao-X-Y.js`: contém o código JavaScript referente à questão X, item Y.

## Tecnologias

* JavaScript
* HTML
* CSS
* Navegador Web
* Git e GitHub
